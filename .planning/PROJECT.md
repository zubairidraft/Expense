# Project: Expense Tracker Pro

## Vision
A high-performance, aesthetically pleasing expense tracking dashboard built for developers and financial enthusiasts, featuring direct visual annotation support via Agentation, autonomous iterative agent execution via Ralph Loop, and spec-driven development via GSD.

## Architecture
- **Frontend Core:** React 19, Vite 8, Vanilla CSS Design System with responsive tokens
- **Visual Feedback:** Agentation (`<Agentation endpoint="http://localhost:4747" />`)
- **Agent Integration:** Roo Code custom modes, Ralph Loop autonomous runner
- **Specs & Methodology:** Spec-Driven Development (SDD) with GSD
